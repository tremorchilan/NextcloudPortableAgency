# Themes

Light/dark variations of the design tokens. A theme file is a partial or full
override of `design/tokens.json`:

```json
{
  "colors": { "background": "#12100E", "surface": "#1E1B18", "text": "#F2EDE6" }
}
```

Apply a theme by merging it over `tokens.json` in the OpenDesign panel
(coming in a later milestone) or by hand.
